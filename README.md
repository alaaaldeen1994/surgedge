# SurgEdge — Surgical Guidance Without Borders

> **Intra-Operative Tele-Guidance, Standardized Curriculum, & 360° Interactive Operating Room (OR) Simulation Suite**  
> *Originated via the Babson College Global Surgery Slingshot Programme & Engineered with Amodisc Ltd.*

---

## 🏥 Platform Overview

**SurgEdge** democratizes access to elite surgical training and real-time intra-operative mentorship across low-resource clinics, conflict zones, and academic medical centers.

### 🌟 Core Capabilities:
1. **Intra-Operative Tele-Guidance & Emergency Dispatch**:
   - Ultra-low-bandwidth WebRTC audio & live AR telestration streaming (<30 kbps prioritised for austere environments).
   - Instant 1-click dispatch to on-call surgical specialists.
2. **Procedural Curriculum Library**:
   - High-definition operative video playback with live AR canvas telestration tools, milestone tracking, and accredited procedural chapters.
3. **360° Interactive Operating Room (OR) 3D Simulation**:
   - WebGL 360° panoramic operating theatre orbit with free drag, smooth zoom in/out (`🔍+` / `🔍-`), glowing 3D holographic AR alignment guides, and real-time ECG oscilloscope telemetry (`72 BPM`).
4. **Faculty Dashboard & Video Upload Studio**:
   - Role-gated portal (Passcode: `slingshot2026`) for curriculum video uploading, mentor scheduling, and tele-guidance audit logs.

## 🚀 Quick Start (Local Run)

```bash
# Clone the repository
git clone https://github.com/<YOUR_USERNAME>/surgedge.git
cd surgedge

# Start the server
npm start
```
Then visit `http://localhost:3000` in your browser.

---

## 🚂 Deploy to Railway (1-Click)

1. Push your repository to **GitHub**.
2. Go to [Railway.app](https://railway.app) and click **"New Project"**.
3. Select **"Deploy from GitHub repo"** and choose `surgedge`.
4. Railway will automatically detect `package.json` and `server.js`, deploy in under 60 seconds, and generate a live public HTTPS URL (e.g. `https://surgedge.up.railway.app`).
